# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private reporting instead: go to the **Security** tab of
[Alan468767/opencode-prompt-rail](https://github.com/Alan468767/opencode-prompt-rail)
and choose **Report a vulnerability**. That opens a private advisory visible only
to the maintainers.

Please include:

- affected version;
- OpenCode and OpenCode Desktop version;
- what the plugin can be made to do that it should not;
- steps to reproduce.

You can expect an initial response within a week.

## Scope

The plugin runs inside OpenCode Desktop and reads the session transcript. It has
no network access of its own and does not persist prompt text. Reports about the
OpenCode host itself belong in the
[OpenCode issue tracker](https://github.com/anomalyco/opencode/issues).
